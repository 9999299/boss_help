# boss_help 侧边栏 UI 美化设计

## 目标

在不改变业务逻辑、API 和数据结构的前提下，把 Chrome 侧边栏从朴素功能界面升级为现代求职 SaaS 风格，并将品牌统一为 `boss_help`。

成功标准：

- 400px 宽度下五个标签页可横向滚动且不拥挤。
- 品牌名在侧边栏标题、页面 `title`、扩展 `manifest` 中统一为 `boss_help`。
- 全部现有功能与测试保持通过。
- 视觉层级清晰：主操作、次操作、危险操作、状态提示一眼可辨。

## 视觉系统

在 `src/styles/sidebar.css` 顶部定义设计令牌：

- 主色：`#0E9F7E`；hover `#0B8468`；浅色底 `#E7F6F1`。
- 强调色：`#F5A524`，用于缺口与待核实状态。
- 中性色：页面背景 `#F5F7F6`，卡片 `#FFFFFF`，正文 `#1F2A32`，次要文字 `#66727C`，边框 `#E3E8E6`。
- 语义色：成功 `#12B76A`，警告 `#F79009`，错误 `#E5484D`。
- 字号：12/13/14/18px；正文行高 1.55。
- 圆角：8/12/16/999px；阴影使用两级柔和阴影。
- 统一按钮三级样式：主按钮（青绿实底）、次按钮（浅底/描边）、幽灵按钮（无底）。
- 输入框统一 focus ring；状态提示统一为带左侧色条的浅色卡片。
- 增加细滚动条样式，并在 `prefers-reduced-motion` 下关闭动效。

## 布局与品牌

### 顶部品牌栏

- 粘性定位，毛玻璃背景。
- 左侧渐变方形 logo「B」，右侧显示 `boss_help` 与副标题「AI 求职助手」。
- 品牌栏与内容区用细边框分隔。

### 标签页

- 五个标签改为横向可滚动 pill 分段控件。
- 激活项使用主色实底白字；每个标签配内联 SVG 图标。
- 仅调整 `Sidebar.jsx` 的结构与图标，不改变标签状态逻辑。

### 内容区

- 各区块统一卡片化：白底、细边框、圆角、轻微阴影，hover 时微浮起。
- 表单标签使用中等字重，输入框圆角并带 focus ring。
- 岗位分析结果的基本信息区改为信息网格 + 状态 chip。
- 经历库、岗位定制、简历编辑、导出页沿用现有类名，仅统一视觉层级。
- 主操作按钮更突出，危险操作使用描边红样式。

### 品牌文案

- `public/manifest.json`：`name` 与 `action.default_title` 改为 `boss_help`；`description` 改为「AI 分析职位要求并生成针对性简历」。
- `public/sidebar.html`：`title` 改为 `boss_help`。
- `README.md`：标题体现 `boss_help`。
- `src/__tests__/Sidebar.test.js`：品牌断言同步更新。

## 实现范围

- 重写 `src/styles/sidebar.css`，保留全部现有类名，新增设计令牌和少量新类。
- 仅对 `Sidebar.jsx` 的 header 与标签页做轻量结构调整。
- 不修改业务逻辑、API、数据结构或其他组件行为。

## 验证

- `npm test -- --runInBand`
- `npm run lint`
- `npm run build`
- 手动或以构建后页面检查 400px 宽度下的标签滚动、长文本换行和禁用态。
