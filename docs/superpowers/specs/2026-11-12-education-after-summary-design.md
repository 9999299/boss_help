# 教育经历移到个人简介之后的设计

## 背景

当前简历编辑器中「教育经历」位于工作经历、项目经历之后；PDF/Word 导出中教育经历位于最后。用户希望教育经历紧跟个人简介/个人信息，提升简历阅读顺序。

## 目标

- 简历编辑器：教育经历区块移动到个人信息区块之后、工作年限之前。
- PDF 导出：教育经历区块移动到个人简介之后、技能之前。
- Word 导出：教育经历区块移动到个人简介之后、技能之前。
- 保持教育经历字段、样式和保存逻辑不变。

## 非目标

- 不调整工作年限、技能、工作经历、项目经历、公司经历、个人优势的相对顺序。
- 不修改数据结构、导出样式或表单字段。

## 变更明细

### 1. 简历编辑器（`src/sidebar/components/ResumeEditor.jsx`）

将 `教育经历` 的整个 `<div className="section">…</div>`（约 469–565 行）移动到 `个人信息` 区块结束之后（约 134 行之后），位于 `工作年限` 区块之前。

### 2. PDF 导出（`src/utils/resumeHtml.js`）

模板输出顺序由：

```text
个人简介 → 技能 → 工作经历 → 项目经历 → 公司经历 → 个人优势 → 教育经历
```

改为：

```text
个人简介 → 教育经历 → 技能 → 工作经历 → 项目经历 → 公司经历 → 个人优势
```

仅调整 `${eduHtml}` 在模板中的位置。

### 3. Word 导出（`src/utils/resumeDocx.js`）

将教育经历生成逻辑（`if ((data.education || []).length) { … }`，约 181–190 行）移动到个人简介生成逻辑之后、技能生成逻辑之前。

## 测试策略

- `src/__tests__/ResumeEditor.test.js`：新增断言，教育经历标题在 DOM 中位于工作年限之前。
- `src/__tests__/resumeHtml.test.js`：新增断言，HTML 中 `教育经历` 位于 `个人简介` 之后、`技能` 之前。
- Word 导出无文本快照测试，依赖现有 Blob 生成测试与人工检查。
- 运行 `npm test -- --runInBand`、`npm run lint`、`npm run build`。

## 风险

- 纯顺序调整，无数据或接口变更；风险低。
