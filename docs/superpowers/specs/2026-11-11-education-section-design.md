# 简历教育经历区块设计

## 目标

在简历编辑器中手动补充大学经历，并让导出的 HTML 简历包含教育经历。

## 决策

- 教育经历由用户手动填写，不由 AI 生成，避免伪造学校/专业。
- 字段：学校名称、专业、学历、起止时间。
- 支持多条教育经历，可添加和删除。
- 条目按起始时间倒序排列。
- 提供学历模版下拉（大专/本科/硕士/博士），默认本科；添加时把所选学历嵌入新条目，学校/专业/时间仍手动填写。

## 实现

- `src/utils/resumeSchema.js`：新增 `normalizeEducation`，在 `normalizeResume` 中规范化并按时间倒序。
- `src/sidebar/components/ResumeEditor.jsx`：新增「教育经历」区块，空状态提示 + 添加/删除/编辑。
- `src/utils/resumeHtml.js`：教育经历输出「学校 · 专业 · 学历 + 时间」。

## 测试

- schema 规范化与排序。
- 编辑器添加、编辑、保存教育经历。
- 导出 HTML 包含学校、专业、学历和时间。
